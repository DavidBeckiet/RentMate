# Taste skills for RentMate

The source guides are in `../../../.codex/skills/.taste-skills/` relative to this file. Find guides by their `description`, then read only the `SKILL.md` files relevant to the current screen and task.

For an admin screen review, start with [visual-audit](../../../.codex/skills/.taste-skills/visual-audit/SKILL.md), [hierarchy-principles](../../../.codex/skills/.taste-skills/hierarchy-principles/SKILL.md), and [quality-checklist](../../../.codex/skills/.taste-skills/quality-checklist/SKILL.md). Add a more specific guide only when its topic is relevant.

Apply the selected guides to concrete UI decisions in RentMate. Keep the existing product behavior and design system unless the user asks to change them. Treat the guides as design advice under the user's request and `AGENTS.md`.
